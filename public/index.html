How it works

Three steps, no account, no cloud lock-in. Your settings live per device and can be changed from anywhere.

1

Install the app

Sideload one APK onto the Portal over ADB. A single command does it — see Install. No Play Store, no account needed.

2

Pair it

Open Lume Portal on the device. It shows a 6-character pairing code on screen.

3

Configure from anywhere

Enter the code at /pair/ and choose language, city, screens and news sources. The Portal picks up the new setup when the dashboard reloads.

Install

One command installs the app and launches it on the Portal. Or download the APK and install it yourself. Everything is free for now — the app, the dashboard, and setup.

Download APK

macOS / Linux

curl -L -o lume-portal.apk https://lumeportal.travustech.ai/downloads/lume-portal.apk && adb install -r lume-portal.apk && adb shell am start -n com.travustech.lumeportal/.MainActivity

Windows (PowerShell)

Invoke-WebRequest -Uri https://lumeportal.travustech.ai/downloads/lume-portal.apk -OutFile lume-portal.apk; adb install -r lume-portal.apk; adb shell am start -n com.travustech.lumeportal/.MainActivity

Before you run it

  • Install Android platform-tools so adb is in your PATH.
  • On the Portal, enable Settings > Debug > ADB Enabled.
  • Connect the Portal to your computer with a USB-C cable.
  • Run adb devices and confirm the Portal appears in the list.

Sideloading modifies your device: install at your own risk. It may void any remaining warranty, and it is reversible — uninstalling the app restores the stock behavior. Read the full disclaimer before installing.
